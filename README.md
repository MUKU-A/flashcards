# 単語カード

自分専用の単語カードアプリです。Mac と Pixel のブラウザで動き、データは Google ドライブで同期します。

- 問題・ヒント・解答・メモ（それぞれ画像も可）と、複数のタグ
- 暗記モード（全体／タグ1つで絞る）とテストモード（出題数・比率・タグを指定）
- 「暗記中」「暗記済み」の自動判定（テストで2回連続○ → 暗記済み、暗記済みで× → 暗記中）
- オフラインでも使える PWA。Pixel ではアプリとしてインストールできます

---

## 1. 必要なもの

- Node.js 22 以上（Mac なら `brew install node`）
- GitHub アカウント
- Google アカウント（データの保存先）

```bash
npm ci        # 依存パッケージのインストール
npm test      # 出題ロジックなどのテスト
```

## 2. Google Cloud の設定（初回のみ）

[Google Cloud Console](https://console.cloud.google.com/) で次の操作をします。

1. **プロジェクトを作成**します（名前は自由。例：`flashcards`）。
2. 「API とサービス」→「ライブラリ」で **Google Drive API** を有効にします。
3. 「Google Auth Platform」（旧「OAuth 同意画面」）を設定します。
   - アプリ名：自由（例：単語カード）
   - 対象：**外部**
   - 公開ステータス：**テスト** のままで構いません
   - テストユーザー：**自分の Google アカウント**を追加します
   - データアクセス（スコープ）：`.../auth/drive.file` を追加します
4. 「クライアント」→「クライアントを作成」で、**ウェブ アプリケーション**を選びます。
   - 承認済みの JavaScript 生成元
     - `https://<GitHubユーザー名>.github.io`
     - `http://localhost:5173`
   - 承認済みのリダイレクト URI
     - `https://<GitHubユーザー名>.github.io/<リポジトリ名>/`（**末尾の `/` まで**正確に入れてください）
     - `http://localhost:5173/`
5. 表示された **クライアント ID**（`xxxx.apps.googleusercontent.com`）を控えます。秘密情報ではありません。

> `drive.file` は「このアプリが作ったファイルだけ」を扱える最小限の権限です。ドライブの他のファイルは見えません。

## 3. 手元で試す（任意）

```bash
cp .env.example .env.local    # VITE_GOOGLE_CLIENT_ID にクライアントIDを入れる
npm run dev                   # http://localhost:5173 を開く
```

クライアント ID を入れなくても、端末内だけで動きます（同期はされません）。

## 4. GitHub Pages で公開

1. GitHub で **Public** のリポジトリを作成します（例：`flashcards`）。無料プランで GitHub Pages を使うには Public である必要があります。データは自分のドライブにしか保存されないので、コードが公開されても問題ありません。
2. このフォルダを push します。
   ```bash
   git init && git add . && git commit -m "first commit"
   git branch -M main
   git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
   git push -u origin main
   ```
3. リポジトリの **Settings → Secrets and variables → Actions → Variables** に、次の変数を追加します。
   - 名前：`GOOGLE_CLIENT_ID`
   - 値：控えておいたクライアント ID
4. **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にします。
5. **Actions** タブで「Deploy to GitHub Pages」を実行します（push 済みなら Re-run）。数十秒で `https://<ユーザー名>.github.io/<リポジトリ名>/` が開けるようになります。

以降は `main` に push するたびに自動で公開されます。

## 5. 端末に入れる

- **Pixel**：Chrome で URL を開き、メニュー（︙）→「アプリをインストール」（または「ホーム画面に追加」）を選びます。
- **Mac**：Chrome のアドレスバー右端のインストールアイコンからアプリとして入れられます。ブラウザのタブのままでも使えます。

初回は右上の「要ログイン」をタップして Google でログインします。テストモードの OAuth なので「Google はこのアプリを確認していません」と出ますが、自分で作ったアプリなので「続行」で進めて大丈夫です。

## 使い方のメモ

### ログインと同期
- ログインは約1時間で切れます。切れても学習や編集はそのまま続けられ、変更は端末に保存されます。右上が「要ログイン」のときにタップすると、再ログインして同期します。
- 同期するタイミング：起動したとき、オンラインに戻ったとき、アプリに戻ってきたとき、変更の数秒後、右上のバッジや設定画面のボタンをタップしたとき。

### キーボード操作（Mac）
| キー | 動作 |
|---|---|
| Space / Enter | 答えを見る |
| H | ヒントを見る |
| 1 / 2 / 3 | × / △ / ○ |
| ⌘ + Enter | カードを保存 |

### 一括登録の形式
スプレッドシートからコピーして貼り付けられます（TSV）。CSV でも登録できます。

```
問題	ヒント	解答	メモ	タグ
HTTPSの標準ポート番号は？		443		IT;ネットワーク
```

- タグが複数ある場合は `;` で区切ります。
- 1行目が「問題」で始まる場合は見出し行として読み飛ばします。

### 出題のルール
- **暗記モード**：「暗記中」のカードをランダムに出題します。一巡するまで同じカードは出ません。回答は記録されますが、状態は変わりません。
- **テストモード**：「暗記中：暗記済み」を指定した比率（初期値 7:3、端数は暗記中に寄せる）で選びます。
  - どちらのグループも、**3割（切り上げ）は最後にテストしてから最も長く経ったカード**（未テストのカードが最優先）にします。残りは完全にランダムです。
  - どちらかが足りなければ、もう一方で埋めます。
- **暗記中のカード**：テストで2回連続○になると「暗記済み」になります。△か×で連続回数はリセットされます。暗記モードの回答は数えません。
- **暗記済みのカード**：テストで×になると「暗記中」に戻ります。
- **「暗記済みへ」ボタン**：押すとすぐに暗記済みになります。数秒間は「元に戻す」で取り消せます。

## Google ドライブ上のデータ

```
マイドライブ/Flashcards/
  cards.json                  … カードと画像の対応表
  events-<端末ID>-<年月>.json   … 回答と状態変更の履歴（各端末が自分のファイルだけに書く）
  images/<画像ID>.jpg
```

- 状態（暗記中／暗記済み）は保存していません。履歴から毎回計算しています。そのため、端末同士で状態が食い違うことはありません。
- カードの内容は、更新日時が新しい方を採用して統合します。
- ブラウザのデータを消しても、ログインすればドライブから復元されます。

## 開発

```
src/
  logic/        出題・状態判定・CSV・統計（純粋な関数。tests/ でテスト）
  sync/         Google ログイン・Drive API・同期
  ui/pages/     各画面
  ui/components 共通部品（出題カード、タグ入力、画像入力、グラフ）
  data.ts       端末内データ（IndexedDB）の読み書き
```

- `npm run dev`：開発サーバーを起動
- `npm test`：テストを実行
- `npm run build`：`dist/` にビルド
